# AI Resume Builder – ATS‑Optimized Resume Generator

An intelligent web application that transforms a user’s experience and target job description into tailored, ATS‑friendly resumes in seconds using large language models.

Recruiters scan hundreds of resumes; this tool helps candidates stand out by automatically optimizing content for relevance, clarity, and ATS keyword matching.

## Problem

Job seekers struggle to:
- Tailor resumes for each application  
- Beat ATS filters and keyword checks  
- Write strong, impact-focused bullet points  

## Solution

A web app where users:
1. Enter their experience and skills  
2. Paste a target job description  
3. Get an optimized, ATS-friendly resume with strong bullets and relevant keywords  

## Features

- Step-by-step resume creation flow with live preview  
- LLM-based bullet point optimization for impact and clarity  
- ATS scoring and keyword matching against job descriptions  
- Multiple professional, ATS-safe templates  
- Export resumes as PDF/DOCX  
- User authentication and saved resume versions  

## Tech Stack

- Frontend: Next.js (React, TypeScript)  
- Backend: FastAPI (Python)  
- Database: PostgreSQL  
- AI: LLM APIs for text generation and optimization  
- Infra: Docker, GitHub Actions (CI/CD), cloud hosting  

## How to Run (Local)

1. Clone the repo:
   ```bash
   git clone https://github.com/vijay455-4444545/AI-Resume-Builder-ATS-Optimized-Resume-Generator.git
   cd AI-Resume-Builder-ATS-Optimized-Resume-Generator
   ```
2. Start with Docker:
   ```bash
   docker compose up --build
   ```
3. Open: http://localhost:3000
